# mobile-layout

## Requirement: 上证指数风向标在移动端不出现重叠
上证指数"市场风向标"卡片的行情区域（价格+涨跌幅）在移动端（屏幕宽度 ≤ 768px）SHALL 不与名称信息区域重叠，内容应完整展示在容器内。

### Scenario: 移动端（≤768px）查看上证指数卡片
- **WHEN** 用户在移动端浏览器（宽度 ≤ 768px）打开网站
- **THEN** 上证指数卡片中价格和涨跌幅纵向排列于右侧，不与左侧名称/代码文字重叠

### Scenario: 超小屏幕（≤480px）查看上证指数卡片
- **WHEN** 用户在超小屏设备（宽度 ≤ 480px）打开网站
- **THEN** 价格字号进一步缩小，卡片内容不溢出容器边界
