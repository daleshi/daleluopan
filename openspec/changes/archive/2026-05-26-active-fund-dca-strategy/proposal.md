## Why

当前「投资策略」Tab 仅有「温度计定投策略」（指数定投），缺少**主动基金定投策略**的支持。
我（用户）实际持有两只主动基金 — 兴全商业模式（乔迁，163415）与大成睿享 A（徐彦，008269），它们各自有一套基于
**沪深300 PE 分位 + 基金自身表现** 的动态定投规则，但这些规则目前只能**靠手动对照执行**，体验差、易遗漏。

同时，对原始规则进行 dry-run 后发现：
1. **乔迁原规则在 PE 50%~80% 区间完全无规则覆盖**，且高估档（80-90%）+（≥90%）使用 AND 联结，
   导致 A 股大部分时间都掉进"灰色地带"，无法触发减半/暂停（见 explore 阶段实证）。
2. **徐彦原规则在 PE 80%~85% 存在一段窄缝空白**。

因此本变更同时完成 **「补全规则空白 + 落地动态计算 + 前端展示」** 三件事。

## What Changes

### 规则修订（用户已确认）

**乔迁补全版（套餐 ②，OR 联结）**
| 档位 | 修订后规则 | 倍数 |
|---|---|---|
| 🔴 加倍定投 | `沪深300 PE分位 ≤ 20%` AND `基金回撤 ≥ 20%` | 200% |
| 🟡 减半定投 | `沪深300 PE分位 ∈ [80%, 90%)` AND `近3月涨幅 ≥ 15%` | 50% |
| 🟣 暂停定投 | `沪深300 PE分位 ≥ 90%` （**OR 联结，去掉"涨6月≥40%"附加条件**） | 0% |
| 🟢 正常定投 | 兜底（其它一切情况） | 100% |

**徐彦补全版（PE 80%~85% 归并到减半）**
| 档位 | 修订后规则 | 倍数 |
|---|---|---|
| 🔴 加倍定投 | `沪深300 PE分位 ≤ 20%` AND `基金回撤 ≥ 15%` | 200% |
| 🟢 正常定投 | `沪深300 PE分位 ∈ [20%, 80%)` | 100% |
| 🟡 减半定投 | `沪深300 PE分位 ∈ [80%, 95%)` | 50% |
| 🟣 暂停定投 | `沪深300 PE分位 ≥ 95%` | 0% |

### 功能新增

- **新增**「主动基金定投策略」section（在「投资策略」Tab 内，温度计定投之上或之下，与之并列）
- 每只主动基金（默认 163415、008269）一张策略卡片，展示：
  - 当前档位徽章 + 本月实际定投金额
  - 触发依据（PE 分位 / 回撤 / 近期涨幅 等关键指标命中情况）
  - 全部规则一览（哪条命中、哪条未触发）
  - 末次计算时间 + 数据日期
- **新增** 后端 API:
  - `GET /api/strategy/active-fund-plans` — 读取策略配置（公开）
  - `POST /api/strategy/active-fund-plans` — 新增/更新单只基金的策略（管理员）
  - `POST /api/strategy/active-fund-plans/delete` — 删除（管理员）
  - `GET /api/strategy/active-fund-recommendations` — 实时计算两只基金当前档位（公开）

### 数据结构

新增 `data/active-fund-strategy.json`，结构详见 design.md。

## Capabilities

### New Capabilities

- **`active-fund-dca-strategy`**：主动基金定投策略管理与实时档位计算。
  - 配置：每只主动基金的基准指数、月定投基准金额、规则集合（含 AND/OR 条件组）、档位倍数。
  - 计算：拉取最新沪深300 PE 分位、基金净值衍生指标（当前回撤 / 近 3M 涨幅 / 近 6M 涨幅），
          按规则优先级（暂停 > 减半 > 加倍 > 正常兜底）匹配，输出当前档位 + 推荐定投金额 + 触发依据。
  - 展示：策略卡片 + 规则逐条扫描结果。

### Modified Capabilities

无（本变更是新增 capability，不修改现有的 `dca-thermometer-recommendation`）。

## Impact

### 后端
- 新增文件：`services/activeFundStrategyEngine.js`（规则引擎 + 衍生指标计算，约 250 行）
- `server.js`：新增 4 个 API 路由（约 +120 行）
- `services/fundFetcher.js`：暴露/复用净值序列（`netWorthTrend`），用于计算回撤与涨幅
- 新增数据文件：`data/active-fund-strategy.json`（首次启动时自动写入两只基金的预设规则）
- 智能缓存键：`active-fund-recommendations`（TTL：交易时段 5min，非交易 30min；底层 PE 与基金数据已自带缓存）

### 前端 (`public/index.html`)
- 新增 HTML section（约 +50 行）：主动基金定投策略容器
- 新增 JS 模块（约 +200 行）：`loadActiveFundRecommendations()` / `renderActiveFundCards()` /
  `renderRuleScanList()` / 编辑表单（管理员可视化配置）
- 新增 CSS（约 +60 行）：档位徽章颜色、规则扫描列表样式
- 移动端 More 菜单中"投资策略"图标无需改动（沿用现有入口）

### 不影响
- 现有「温度计定投策略」(`dca-thermometer-recommendation`) 完全不受影响，配置与展示并行存在
- 现有指数/股票/ETF/主动基金 watchlist 与行情逻辑不变
- 现有认证/权限模型不变（写操作 requireAdmin，读操作公开）
