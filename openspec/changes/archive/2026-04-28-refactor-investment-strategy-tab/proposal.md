## Why

当前"投资策略"Tab 包含三个部分：操作策略、综合投资建议、温度计定投策略。其中"操作策略"和"综合投资建议"两部分内容实用性不强，信息过载，用户反馈价值有限。同时，"温度计定投策略"部分仅展示配置，未根据当前温度给出直观的定投建议，用户需要自己对照温度表计算，体验不佳。此外，界面存在错别字"低谷"，应改为"低估"。

## What Changes

- **删除**"操作策略"部分（section-title: 操作策略 + Action Plan badge）
- **删除**"综合投资建议"部分（section-title: 综合投资建议 + Professional Advice badge）
- **修改**"温度计定投策略"部分：
  - 对每个已配置的指数，获取当前有知有行温度数据
  - 根据当前温度和配置的温度区间，自动计算并显示当前定投比例和金额
  - 例如：沪深300 当前温度 61°，匹配"50°-70°"区间 → 显示"减半定投，每月定投 500 元"
- **修改错别字**：所有"低谷"改为"低估"（涉及默认配置、表单选项）

## Capabilities

### New Capabilities

- `dca-thermometer-recommendation`: 温度计定投实时建议功能。根据指数当前温度、配置的温度区间和定投金额，计算并展示当前应执行的定投策略（如：正常定投、减半定投、暂停定投等）。

### Modified Capabilities

（无现有 capability 需要修改）

## Impact

- **前端代码** (`public/index.html`):
  - 删除 ~40 行 HTML（操作策略 + 综合投资建议 sections）
  - 修改 `renderDcaPlans()` 函数，增加温度获取和定投建议计算逻辑
  - 修改 `DEFAULT_DCA_LEVELS` 常量，"低谷" → "低估"
  - 修改表单模板中的"低谷"选项 → "低估"
- **后端 API**（可能不需要修改）:
  - 现有 `/api/thermometer/detail?code=` 已能获取温度数据
  - 现有 `/api/strategy/dca-plans` 已能获取定投策略配置
  - 前端可直接调用现有 API 完成计算和展示
- **用户体验**:
  - 简化投资策略 Tab，只保留核心的"温度计定投策略"
  - 直观显示当前定投建议，降低决策成本
