## Why

「投资策略」Tab 目前覆盖了指数定投（温度计驱动）和主动基金定投（PE 分位 + 基金表现），但**黄金资产**尚未覆盖。
用户计划长期定投黄金 ETF 联接基金（每月 1000 元、持有 10+ 年、期望年化 ~10%），但黄金与股票的估值逻辑完全不同：

- **黄金没有内在估值（无 PE/PB）**，只有相对价格分位与均线偏离可参考
- **黄金长期没有现金流回报**，必须通过**主动止盈**才能锁定波段收益
- **黄金极易在历史高位震荡多年**，规则若不留兜底，定投容易长期归零

通过对真实数据 dry-run（华安黄金 ETF 联接 A 000216，2026-05-24 净值 3.4561）发现：
- 当前近 5 年价格分位 **92.96%**，从近1年高点回撤 **19.61%**——处于"历史高位 + 短期已调"的微妙位置
- 2021-01 起按 1000元/月定投至今 5.4 年，累计收益 **96.23%**（粗估年化 28.38%），早应触发 30%/60% 止盈

因此本变更引入一套**专为黄金设计的动态定投策略**，包含：
- **买入端**：单因子价格分位 + 回撤兜底，4 档定投强度
- **持有端**：3 档止盈机制（用户确认型），分批锁定收益

## What Changes

### 规则锁定（用户已确认）

**买入端（每月评估，按防御优先匹配）**

| 优先级 | 档位 | 条件 | 倍数 |
|---|---|---|---|
| 1 | 🟣 暂停定投 | 近 5 年价格分位 ≥ 90% | 0% |
| 2 | 🔴 加倍定投 | 近 5 年价格分位 ≤ 20% **OR** 从近1年高点回撤 ≥ 25% | 200% |
| 3 | 🟡 减半定投 | 近 5 年价格分位 ∈ [70%, 90%) | 50% |
| 4 | 🟢 正常定投 | 兜底（其它一切情况） | 100% |

**核心决策**：暂停档使用"分位 ≥ 90%" 单条件，**优先于加倍档**——
即使深跌也不抄底（高位接飞刀风险高、长期持有视角下宁可错过）。

**持有端（每月评估持仓总收益）**

| 档位 | 触发条件 | 操作 | 触发次数 |
|---|---|---|---|
| 💰 一档止盈 | 总收益 ≥ 30% | 建议卖出持仓 10% | 仅 1 次 |
| 💰 二档止盈 | 总收益 ≥ 60% | 建议卖出持仓 20% | 仅 1 次 |
| 💰 三档止盈 | 总收益 ≥ 100% | 建议卖出持仓 30% | 仅 1 次 |

每档独立触发，用户在 UI 上手动点击「已止盈」后系统记录 `triggeredAt` 时间戳，下次评估时跳过该档。
（**用户确认型**，而非自动标记，防止"提示了但未操作"导致下次仍提示。）

### 功能新增

- **新增**「黄金定投策略」section（在「投资策略」Tab 内，与指数温度计、主动基金定投并列）
- 每只配置的黄金基金一张策略卡片，展示：
  - 当前买入档位 + 本月推荐定投金额 + 触发依据
  - 持仓累计成本 / 累计份额 / 当前市值 / 累计收益率
  - 止盈档位状态（已触发 / 未触发 / 当前触发中）
  - 持仓记录列表（含定投、止盈两类记录）

- **新增** 后端 API:
  - `GET /api/strategy/gold-plans` — 读取黄金策略配置（公开）
  - `POST /api/strategy/gold-plans` — 新增/更新（管理员）
  - `POST /api/strategy/gold-plans/delete` — 删除（管理员）
  - `GET /api/strategy/gold-recommendations` — 实时计算买入档位 + 止盈状态（公开）
  - `GET /api/strategy/gold-holdings` — 读取持仓记录列表（公开）
  - `POST /api/strategy/gold-holdings` — 新增持仓记录（管理员）
  - `POST /api/strategy/gold-holdings/delete` — 删除持仓记录（管理员）

### 数据结构

- 新增 `data/gold-strategy.json`：策略配置（含买入规则集 + 止盈档配置）
- 新增 `data/gold-holdings.json`：持仓记录（每月定投 / 每次止盈 各为一条记录）

详见 design.md。

## Capabilities

### New Capabilities

- **`gold-dca-strategy`**：黄金动态定投策略与持仓管理。
  - 买入端：基于价格分位（近5年）+ 短期回撤的 4 档规则，沿用 `active-fund-dca-strategy` 的规则引擎扩展
  - 持有端：止盈档评估 + 用户确认触发
  - 持仓管理：手工录入定投/止盈记录，自动累计成本、份额、当前市值与收益率

### Modified Capabilities

无（本变更新增独立 capability，不修改现有 `active-fund-dca-strategy` 或 `dca-thermometer-recommendation`）。

## Impact

### 后端
- 新增文件：`services/goldStrategyEngine.js`（黄金规则引擎 + 持仓汇总计算，~250 行）
- 复用：`services/activeFundStrategyEngine.js` 的 `evaluateRule` / `matchStrategy`（黄金的买入档位匹配是同一套引擎）
- 复用：`fetchEastmoneyFundData()` 拉取基金净值序列（已支持 000216 华安黄金联接 A）
- `server.js`：新增 7 个 API 路由（~250 行）
- 新增字段白名单：`fundPricePercentile5Y`（近5年价格分位）/ `fundDrawdown1Y`（从近1年高点回撤）
- 新数据文件：`data/gold-strategy.json` + `data/gold-holdings.json`（首次启动自动注入默认配置：000216 + 默认规则）
- 缓存键：`gold-recommendations`（TTL 与 active-fund 相同：交易 5min / 休市 30min）

### 前端 (`public/index.html`)
- 新增 HTML section：黄金定投策略容器（约 +80 行）
- 新增 JS 模块（约 +400 行）：策略卡片渲染 + 持仓记录表 + 止盈确认弹窗 + 配置表单
- 新增 CSS（约 +120 行）：黄金主题色（金色徽章）、止盈进度条、持仓记录表
- 接入 `switchTab('strategy')` 钩子

### 不影响
- 现有「指数温度计定投」「主动基金定投」section 完全不动
- 现有 `position-records` / `position-benchmark` 完全不动（这两个是指数加仓基准，与黄金持仓语义不同）
- 现有认证模型不变（读公开，写 requireAdmin）

### 验收 Dry-Run

按当前数据（华安黄金联接 A 净值 3.4561 @ 2026-05-24）跑修订规则：

```
买入端判定
  近5年价格分位 = 92.96% ≥ 90%
  → 🟣 暂停定投，本月推荐定投金额 = 0 元

持有端（假设按规则从 2021-01 起按建议定投，累计成本 65000 元）
  当前累计收益 ≈ 96.23%
  → 30% 止盈档 ⚠ 应提示已触发（用户未确认前每次仍提示）
  → 60% 止盈档 ⚠ 应提示已触发
  → 100% 止盈档 未触发（差 3.77 个百分点）
```
