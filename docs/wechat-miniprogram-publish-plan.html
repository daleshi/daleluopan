三、关键决策分叉：你的主体是个人还是企业

企业 / 个体工商户主体 推荐路线

  • 可配置业务域名 → web-view 套壳 1 天上线
  • H5 一行代码不改
  • 认证费 300 元/年（个体户 30 元/年）
  • 后续想做原生，可逐步替换页面

个人主体 web-view 不可用

  • 无「业务域名」入口，套壳方案直接否决

这里有个容易误解的点：个人主体不能用 web-view，但可以用 wx.request 访问已备案的 HTTPS 域名。所以「个人主体 + 原生小程序」在技术上是完全通的路，卡你的只有类目审核，不是技术。

web-view 的三个已知坑（骨架已规避前两个）：
  • bindload 不能命名为 onLoad，会覆盖页面生命周期（骨架中已用 onWebLoad）。
  • web-view 自动铺满整页，其他组件盖不住，加载态必须用 wx.showLoading。
  • web-view 内 Cookie 与手机浏览器 / 微信内置浏览器不共享，用户需在小程序里重新登录一次。

小程序侧请求封装（server.js:532 的 extractToken() 已支持 Bearer，无需改后端鉴权）：

// utils/api.js
const BASE = 'https://daleluopan.com';
let TOKEN = wx.getStorageSync('ic_token') || '';

function request(path, method = 'GET', data = {}) {
  return new Promise((resolve, reject) => {
    wx.request({
      url: BASE + path, method, data,
      header: { 'Content-Type': 'application/json',
                'Authorization': TOKEN ? `Bearer ${TOKEN}` : '' },
      success: (res) => {
        if (res.statusCode === 401) {
          wx.removeStorageSync('ic_token');
          wx.navigateTo({ url: '/pages/login/index' });
          return reject(new Error('未登录'));
        }
        if (res.data && res.data.success) return resolve(res.data.data);
        reject(new Error((res.data && res.data.error) || '请求失败'));
      },
      fail: reject,
    });
  });
}

async function login(username, password) {
  const data = await request('/api/auth/login', 'POST', { username, password });
  TOKEN = data.token;
  wx.setStorageSync('ic_token', TOKEN);
  return data;
}
