大乐罗盘 · 微信小程序上线操作步骤

个人主体 · 原生小程序 · 复用已备案域名 daleluopan.com 的现有 API

AppID 已注册 域名已 ICP 备案 HTTPS 已就绪 骨架代码已就绪
先纠正一个认知：「发布网站到小程序」这三件事里，只有第三件是"发布" 微信小程序不是浏览器。https://daleluopan.com 那个 795KB 的 H5 页面无法直接搬进小程序—— 个人主体没有「业务域名」权限，web-view 组件用不了。所以真实做法是：
① 后端 API 继续跑在 daleluopan.com 上（不用动）→ ② 小程序用 wx.request 调这批 API 渲染自己的页面（骨架已写好）→ ③ 走完备案+审核后点「发布」。
数据在同一个服务器、同一套接口，小程序只是多了一层前端壳。

整体时间线

第 1 天配域名+跑通
第 1 天真机扫码预览
第 1 天上传体验版
今天提交小程序备案

前三步今天就能全部做完，手机扫码就能用。真正卡时间的是备案，所以第 4 步务必今天就提交，别等前面做完再说。

操作步骤

1
配置服务器域名
10 分钟 · 今天必做

打开 mp.weixin.qq.com 扫码登录你的小程序，按这个路径走：

管理›开发管理›开发设置›服务器域名 （部分版本显示为 开发›开发设置›服务器域名）

  1. 点「修改」，管理员微信扫码确认
  2. request 合法域名 填：https://daleluopan.com
    • 必须以 https:// 开头
    • 不能带端口，写成 https://daleluopan.com:443 会全部请求失败
    • 结尾不要加斜杠
  3. 其余三类（uploadFile / downloadFile / socket）暂时留空，骨架用不到
  4. 保存。域名已备案，立即生效，不用等
验证是否配成功 填完后刷新页面，能看到该域名出现在列表里即成功。若提示「域名未备案」，说明微信侧同步延迟，等 24 小时再试。
2
填 AppID 并导入开发者工具
15 分钟

没装开发者工具的话先装：微信开发者工具 · 稳定版 Stable Build（developers.weixin.qq.com/miniprogram/dev/devtools/download.html）

方式 A（推荐，一条命令） —— 在项目根目录执行：

bash scripts/set-mp-appid.sh wx你的AppID

脚本会校验格式（wx + 16 位十六进制）并写入 miniprogram/project.config.json。

方式 B（手动） —— 打开 miniprogram/project.config.json，改这一行：

"appid": "wx1234567890abcdef",

然后开发者工具 → 导入项目 → 目录选 /Users/daleshi/daleluopan/miniprogram → AppID 会自动带出 → 点「导入」。

导入时的两个坑 ① 目录要选到 miniprogram 这一层，不要选项目根目录，否则会报「未找到 app.json」；
② 不要用「测试号」，必须填你自己的 AppID，不然第 5 步上传不了代码。
3
本地跑通，确认真拿到了数据
10 分钟

导入后模拟器会自动编译。你应该看到：

Tab应该显示的内容
估值顶部「市场温度 XX°」+ 9 个指数卡片（沪深300、中证500、中证消费、纳斯达克100 等），含 PE/PB/ROE/股息率、PE 百分位水位条、30 日迷你走势图
温度全市场温度环形图 + 低估/适中/高估三档概率 + 12 个指数温度排序
我的服务地址 https://daleluopan.com、数据来源说明

点任一指数卡片 → 跳到温度页看该指数详情。

关于「不校验合法域名」 项目里 urlCheck 已设为 false，所以开发者工具里能直接跑。这只在开发者工具和手机调试模式下有效， 正常扫码预览仍要走第 1 步配好的域名。第 1 步做完之后，建议去「详情 → 本地设置」把它取消勾选再测一次，才是真实验证。
如果页面空白 / 提示网络异常 先看 Console 报错，再对照文末排错表。最常见：request 域名没配、AppID 填成测试号、后端没起。
4
真机预览，手机扫码体验
5 分钟

开发者工具顶部点 「预览」 → 出现二维码 → 用管理员或已添加的体验成员微信扫码。

到这一步，你手机上已经有一个能用的大乐罗盘小程序了。

注意：开发版二维码有效期 25 分钟，过期重新点预览。开发版的请求会走真实域名校验， 所以这一步能跑通 = 第 1 步配置无误。

5
上传为体验版（长期可访问）
10 分钟

开发者工具点 「上传」 → 填版本号（如 1.0.0）和备注 → 确定。

然后后台：管理›版本管理 → 在「开发版本」里把刚上传的版本选为体验版。

管理›成员管理›体验成员 添加你想分享的人（个人主体最多 15 位）。

体验版不需要备案、不需要审核 这是个人主体最实用的阶段：功能完整、能长期使用、能给别人扫码体验，完全绕开审核。自用或给朋友用，到这里就够了。
6
完善小程序基本信息 + 选类目
20 分钟 · 备案前必须做

设置›基本设置 里补齐：名称、头像、简介、服务类目。

类目选择：这一步决定你能不能过审 A 股行情属于「金融业 - 股票信息服务平台」，需要《增值电信业务经营许可证》+ 沪深交易所《证券信息经营许可合同》， 个人主体 100% 拿不到，选了必被驳回。

建议：定位成「个人投研记录工具」，类目选 工具 → 信息查询（或「工具 → 效率」）。 简介里强调"记录个人持仓与估值观察"，不要写"提供行情资讯""投资建议"。

即便如此，审核仍可能按页面实际内容判定为金融信息服务。这是灰度操作，要有被驳回的心理准备。
7
提交小程序备案
今天就要提交 · 1-20 工作日

入口二选一：

  • 未上架小程序：后台首页点「去备案」
  • 或：设置›小程序备案›去备案

流程：填写主体信息（个人：身份证）→ 小程序负责人信息 → 小程序信息（名称/类目/服务内容）→ 上传证件 → 人脸核验（本人微信扫码）→ 微信初审 1-2 工作日 → 工信部短信核验 → 通管局终审。

三个必须记住的点 ① 工信部会发短信验证码到负责人手机，必须 24 小时内到 beian.miit.gov.cn 完成核验，超时备案失败；
② 个人主体材料很简单：身份证正反面 + 本人人脸核验，不需要营业执照；
③ 备案通过后，备案号要展示在小程序「关于」页面，微信会检查。
8
提交审核并发布
备案通过后 · 1-7 天

备案状态变「已备案」后：管理›版本管理 → 把体验版提交审核 → 填测试信息 → 等审核 → 通过后点「发布」。

一个天然优势：审核员不需要登录就能看到内容 骨架的估值页和温度页都是免登录的，审核员打开就有数据。千万别把登录设成强制前置，否则审核员进不去会直接驳回。

审核常见驳回原因：类目与内容不符、服务内容涉及投资建议、页面存在诱导分享、缺少备案号展示。

登录功能：还需要一步后端部署

骨架的「我的」页有账号密码登录。但当前线上后端还没部署 token 返回，所以现在登录会提示"无 token"。

本地 server.js 的 /api/auth/login 已改好（在响应体里补了 token 和 expiresAt， Cookie 逻辑未动，网页版无感知），需要重新部署到 43.136.122.239 才生效：

bash scripts/package-deploy.sh # 打包并部署（会重启服务）

估值、温度两个核心功能不受影响，不部署也能正常用。只有登录态相关功能需要它。
