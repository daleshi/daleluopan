# 2026-09-29

## 微信小程序发布方案调研（大乐罗盘 Dale Compass）

产出：`docs/wechat-miniprogram-publish-plan.html`

**现状结论**：项目跑在 `43.136.122.239:3200`，无域名 / 无 HTTPS / 无备案；前端是 `public/index.html` 单文件原生 DOM SPA（579KB，含约 28 处手写 Canvas 图表）；后端 `/api/*` 共 60+ 路由。

**关键技术发现**：
- `server.js:532-542` `extractToken()` 已支持 `Authorization: Bearer <token>`，小程序侧可直接复用。
- `server.js:633-660` `/api/auth/login` 只写 HttpOnly Cookie，**响应体不含 token** → 小程序登录态必改项（需在 data 中回传 token）。
- session 存内存 Map，PM2 重启即掉线。
- web-view 仅非个人主体可用；域名强制 HTTPS + ICP 备案 + 443 端口，不支持 IP。
- 金融类目（股票信息服务平台）需《增值电信业务经营许可证》+ 沪深交易所信息经营许可，个人/普通企业不可解 → 建议定位改为「个人投研记录工具」绕开前置审批。

**推荐路径**：A 自用体验版（0.5-1 天，开发者工具勾选「不校验合法域名」直连 IP:3200，不提交审核）→ 并行补域名备案 + Nginx HTTPS → 再决定 web-view 套壳（1 天）或原生重写（2-4 周 MVP）。不建议 kbone（DOM/Canvas 密集踩性能短板）。

## 用户确认为「个人主体」→ 改为原生小程序实现（原生版已产出）

**关键约束**：个人主体无「业务域名」入口 → web-view 否决；但「服务器域名」可配置 → `wx.request` 打 daleluopan.com 完全可行。

**已产出** `miniprogram/` 原生版（可运行）：
- 页面：index（指数估值，tab）/ thermometer（温度计，tab）/ mine（我的，tab）/ login（登录）
- 组件：`components/sparkline`（30 日迷你走势，canvas 2d）、`components/temp-ring`（温度环形图，canvas 2d）
- 工具：`utils/api.js`（wx.request 封装 + Bearer token）、`utils/format.js`（涨红跌绿、估值标签、温度色）
- 已用线上真实数据冒烟：9 个指数卡片、温度 46°/中估、bands 3 档、allIndices 12 条、notes 3 条均正常。

**实测踩坑修正**：走势线最初用 `momentum1m` 着色，导致当日涨的指数配绿线；改为新增 `fmt.trendColor(sparkData)` 按序列首尾涨跌着色（结果：8 跌绿 / 1 涨红，符合近一月实际）。

**后端改动**：`server.js` `/api/auth/login` 响应 data 新增 `token` + `expiresAt`（Cookie 逻辑不动，H5 无感）。**尚未部署到线上**，故小程序登录会提示「无 token」，但估值/温度功能免登录不受影响。

**合规提示（已写入 README）**：个人主体勿选金融类目，建议定位「个人投研记录工具」选「工具-信息查询」；小程序 ICP 备案需单独提交（与域名备案两回事）。
